# v0 Prompt：技术选型与项目初始化

## 使用目标

这一阶段用于让 AI 先完成技术路线规划、项目依赖选择和基础工程初始化，而不是直接生成完整页面。

v0 的核心目标是：

- 确定项目使用 Node.js 生态。
- 确定前端框架、样式方案、语言和包管理工具。
- 为后续自然迭代建立基础项目结构。
- 预留后续图片、视频、3D 模型和智能客服能力。
- 生成最小可运行项目，而不是完整商品页。

## 用户输入提示词

```text
我想做一个面向海外用户的纯钛杯英文独立站。现在还不急着做完整页面，我想先把项目技术栈和工程基础搭好，方便后面逐步增加商品展示、产品图片、视频、3D 模型和客服等功能。

当前先做 v0 阶段：技术选型与项目初始化。

请先不要直接写完整页面，也不要开始做商品详情页。你需要先进入 Plan 阶段，帮我确定技术选型、依赖选择、项目结构和初始化方案。

我的基础要求：

1. 项目要基于 Node.js 生态。
2. 页面后续要适合做独立站、品牌官网和产品展示。
3. 后续可能会接入真实产品图片素材。
4. 后续可能会加入图片/视频混合展示。
5. 后续可能会接入真实 3D 模型，模型格式可能是 OBJ、MTL 和 PNG 贴图。
6. 后续可能会加入右下角英文客服或智能客服。
7. 希望使用现代前端技术，方便后续持续迭代页面和交互功能。
8. v0 阶段只需要完成工程基础，不需要完整视觉设计，不需要 3D，不需要视频，不需要客服。

请你先给我几个技术方案选择，至少包括：

1. 前端框架选择
2. 样式方案选择
3. 3D 技术预留方案
4. TypeScript 或 JavaScript 选择
5. npm 或 pnpm 选择
6. 推荐的项目目录结构
7. v0 阶段需要生成哪些基础文件

等我选择方案后，你再开始创建项目基础代码。
```

## 期望 AI Plan 输出

AI 应该先给用户选择，而不是直接编码。

推荐 AI 输出结构如下：

```text
我会先帮你确定这个独立站的工程基础。考虑到后续可能加入产品图片、视频、真实 OBJ/MTL 3D 模型和客服功能，建议优先选择可扩展的前端技术栈。

请确认以下方案：

1. 前端框架
A. Next.js + React：适合独立站、产品展示、静态资源管理和后续扩展
B. Vite + React：更轻量，适合纯前端展示页
C. 原生 HTML/CSS/JS：最简单，但后续扩展 3D 和客服会更吃力

2. 样式方案
A. Tailwind CSS：适合快速构建响应式品牌页
B. CSS Modules：结构清晰，但开发速度较慢
C. 普通全局 CSS：简单直接，但大型页面维护性较弱

3. 3D 技术预留
A. Babylon.js：适合加载 OBJ/MTL/贴图并制作交互式 3D 查看器
B. Three.js：生态广，但 OBJ/MTL 材质细节需要更多手动处理
C. 暂不安装 3D 依赖，等真正需要 3D 功能时再接入

4. 编程语言
A. TypeScript：适合长期维护和复杂组件
B. JavaScript：更简单，但大型项目可维护性较弱

5. 包管理工具
A. npm：Node.js 默认工具链，兼容性最好
B. pnpm：速度快，但需要确认本地环境

6. v0 基础文件
A. 只生成最小 Next.js 项目
B. 生成 Next.js 项目 + public/products 资源目录
C. 生成 Next.js 项目 + public/products + 基础项目说明文档

请告诉我你的选择，例如：
前端框架 A，样式方案 A，3D 技术预留 A，编程语言 A，包管理工具 A，基础文件 C。
```

## v0 阶段不应该做的事情

v0 不应该：

- 不应该制作完整商品首页。
- 不应该接入真实产品图片。
- 不应该处理视频。
- 不应该加载 3D 模型。
- 不应该添加智能客服。
- 不应该生成复杂品牌视觉。
- 不应该做购买按钮、产品矩阵和场景模块。

## v0 阶段完成标准

v0 完成后应该满足：

- 项目可以通过 `npm install` 安装依赖。
- 项目可以通过 `npm run dev` 启动。
- 首页有一个最小占位页面。
- 项目目录为后续自然增加图片、视频、3D 和客服功能预留好扩展位置。
- 技术栈选择已经能支撑后续图片、视频、3D 和客服功能。
