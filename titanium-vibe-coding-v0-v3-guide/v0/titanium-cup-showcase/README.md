# Titanium Cup Showcase v0

This is the v0 foundation for a premium titanium cup storefront.

The purpose of v0 is not to build the full product page. It establishes the project foundation and technical direction so later iterations can add real product images, video, 3D model loading, and customer support interactions.

## Tech stack

- Node.js
- Next.js
- React
- TypeScript
- Tailwind CSS
- Babylon.js
- Babylon.js Loaders
- npm

## Directory notes

```text
src/app
public/products
```

`public/products` is intentionally empty in v0 except for `.gitkeep`. Later iterations can place real product images, videos, and 3D assets there.

## Commands

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

or:

```text
http://127.0.0.1:3000
```
