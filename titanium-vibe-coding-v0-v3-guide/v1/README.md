# V1 查看说明

这个文件夹是从 `v0` 项目继续生成的第一版真实页面结果。

双击 `启动-v1-页面.bat` 即可启动本地 Next.js 预览：

- 项目目录：`D:\vscode-vibe-demo-portable\titanium-vibe-coding-v0-v3-guide\v1\titanium-cup-showcase`
- 预览地址：`http://127.0.0.1:3000`
- 第一次运行会自动执行 `npm install`

本版重点是把 `v0` 的空白 Next.js 工程推进到一个可查看的纯钛杯基础独立站页面：包含首屏、主推产品、材质卖点、推荐产品列表和底部信息。
