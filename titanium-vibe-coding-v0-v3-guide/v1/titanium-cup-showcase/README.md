# Titanium Cup Showcase v1

This is the v1 basic storefront for a premium titanium cup independent site.

The purpose of v1 is to turn the technical foundation into the first usable product page with real image assets, English copy, product information, conversion buttons, and a recommended product grid.

## Tech stack

- Node.js
- Next.js
- React
- TypeScript
- Tailwind CSS
- Babylon.js
- Babylon.js Loaders
- npm

## Directory notes

```text
src/app
public/products
```

`public/products` contains the product images used by this basic storefront.

## Commands

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

or:

```text
http://127.0.0.1:3000
```
