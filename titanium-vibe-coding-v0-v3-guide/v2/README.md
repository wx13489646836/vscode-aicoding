# V2 查看说明

这个文件夹是从 `v1` 项目继续生成的第二版真实页面结果。

双击 `run-v2.cmd` 或 `启动-v2-页面.bat` 即可启动本地 Next.js 预览：

- 项目目录：`D:\vscode-vibe-demo-portable\titanium-vibe-coding-v0-v3-guide\v2\titanium-cup-showcase`
- 预览地址：`http://127.0.0.1:3000`
- 第一次运行会自动执行 `npm install`

本版重点是把 `v1` 的基础商品页升级为高端品牌媒体页：包含黑金视觉、主推产品图库、图片/视频展示、场景展示、材质卖点和更完整的购买转化信息。
