# Titanium Cup Showcase v2

v2 upgrades the v1 basic storefront into a premium brand media page.

This version includes:

- Dark titanium-inspired visual direction
- Featured product gallery
- Image and video media switching
- Product video section
- Crafted for Every Moment scene section
- Material and trust feature blocks
- Refined recommended product grid

It intentionally does not include:

- 3D model loading
- Smart customer service
- Entry loading tied to 3D assets

Run locally:

```bash
npm install
npm run dev -- --hostname 127.0.0.1 --port 3000
```
